## 📝 App Descriptions

### The Elevator Pitch (Short)
Hydrozoa is a lightweight, high-performance multipoint mirror agent designed to synchronize your repositories across GitHub, GitLab, Gitea, Forgejo, and more. Keep your codebases in sync across multiple providers automatically, ensuring high availability and provider independence.

### The Professional Pitch (Medium)
Hydrozoa is an open-source synchronization engine that acts as a bridge between diverse Git ecosystems. Whether you're mirroring from GitHub to a self-hosted GitLab instance or maintaining a backup on Gitea, Hydrozoa handles the heavy lifting. With real-time telemetry, a Dead Letter Queue (DLQ) for failed syncs, and a sleek, modern dashboard, it provides the visibility and reliability that DevOps teams demand.

### The Technical Deep-Dive (Long)
Hydrozoa is a robust, container-ready agent built for developers who value data sovereignty and redundancy. It supports a wide array of adapters (GitHub, GitLab, Gogs, Forgejo, Gitea) and features a sophisticated sync matrix for granular control over repository mirroring. 
Key features include:
- **Multipoint Sync**: One source, many targets.
- **Automated Provisioning**: Automatically creates target repositories if they don't exist.
- **Real-time Monitoring**: Dashboard with ApexCharts for throughput visualization.
- **Fault Tolerance**: Integrated Dead Letter Queue for replaying failed synchronization events.
- **Security First**: AES-256-GCM encryption for all provider tokens and secure JWT-based authentication.

## 🚀 Where to Advertise (Free & Open Source)

Since Hydrozoa is **Free and Open Source (FOSS)**, the best places to gain traction are communities that value transparency and developer tools:

### 1. Developer Communities
- **Show HN (Hacker News)**: Perfect for a technical launch. Focus on the "why" (provider independence).
- **Reddit**:
    - `r/selfhosted`: Users here love tools that help them manage their own infrastructure.
    - `r/devops`: Focus on the automation and mirroring aspects.
    - `r/opensource`: General FOSS enthusiasts.
    - `r/github` / `r/gitlab`: Target users of specific platforms.
- **Dev.to / Hashnode**: Write a "How I built this" or "Why you need repository mirroring" article.

### 2. Open Source Directories
- **Awesome-Selfhosted**: Submit a PR to the [Awesome-Selfhosted list](https://github.com/awesome-selfhosted/awesome-selfhosted) on GitHub.
- **AlternativeTo**: List Hydrozoa as an open-source alternative to paid mirroring services.
- **LibHunt**: A great place for developers to discover new tools.

### 3. Product Launch Platforms
- **Product Hunt**: Great for a general "vibe" check and initial traffic.
- **Indie Hackers**: Share the journey of building a FOSS tool.

### 4. Direct Outreach
- **GitHub/GitLab/Gitea Forums**: Participate in discussions where users ask about mirroring or backups.
- **Discord/Slack Communities**: Join DevOps and Self-Hosted servers to share the project.
