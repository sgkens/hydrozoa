### Commit Messages

Use Conventional Commits.

Example

```text
feat(scope) message
```

 When committing, I prefer adding files by scope instead of staging everything at once.

Examples of scoped commits

```text
docs update README
config(package.json) add new config properties
feat add new feature
ci update CI
improve refactor core app structure
```

Other appropriate scopes can include `fix`, `test`, `refactor`, etc.
